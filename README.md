# Personal Portfolio — Hemalatha Grandhi

A clean, responsive, content-first portfolio built to showcase copywriting work, brand voice case studies, and short essays. 

Designed with a modern minimalist aesthetic, dark/light mode toggle, and structured case studies.

## ✨ Features

- **Content-First Design:** Focused on typography, readability, and impactful copy presentation.
- **Theme Switcher:** Toggle between light, dark, and auto/system color modes seamlessly via JavaScript.
- **Interactive Essay & Case Study Cards:** Cleanly formatted sections for selected work, brand voice samples, and thought pieces.
- **Fully Responsive:** Lightweight, pure HTML/CSS/JS with zero heavy frameworks or external dependencies.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for optimal SEO and accessibility.
- **CSS3:** Custom properties (CSS variables) for dynamic theme switching and modern CSS Grid/Flexbox layouts.
- **JavaScript (ES6+):** Light script handling the year dynamic update and theme state management.
